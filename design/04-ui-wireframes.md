# FitFlow UI Wireframes

## Navigation Rationale

- Main app uses a bottom `TabView` with 4 destinations: Dashboard, Workouts, Stats, Profile.
- Primary actions are one tap away from dashboard cards/buttons.

## High-Fidelity Mapping Notes

- Dark main experience with green accents for action hierarchy.
- Light profile screen for visual separation from analytics/workout contexts.
- Consistent card spacing and rounded surfaces across tabs.

## Accessibility Notes

- Dynamic Type support is enabled across major screens.
- Interactive controls use at least 44pt touch targets.
- Color system uses high-contrast text/background pairs for dark and light surfaces.
